# strickey 1.0.0

Bring the sound of a mechanical keyboard to your Mac’s built-in keyboard. strickey is a lightweight native menu bar app with recorded Cherry MX switch sounds and simple, local controls.

## What’s included

- Choose recorded Cherry MX Red, Brown, or Blue sounds with PBT keycaps.
- Hear varied recordings for regular keys, Space, Return, and Delete.
- Adjust strickey’s keyboard volume independently while audio follows your Mac’s default output and system volume.
- Preview sounds, pause typing playback, and optionally skip Command and Control shortcuts.
- Open a compact menu bar panel and optionally launch strickey when you sign in.
- Keep preferences on your Mac. strickey does not save or send typed text or keystroke history.

## Requirements

- macOS 14 or later.
- Apple Silicon or Intel Mac.

## Install

1. Open the downloaded DMG and drag `Strickey.app` to Applications.
2. Open strickey, then enable it in **System Settings → Privacy & Security → Input Monitoring**.
3. Quit and reopen strickey to begin hearing typing sounds.
4. Click its menu bar icon to choose a switch profile, adjust volume, or preview sounds.

Secure Input temporarily pauses typing sounds; sound preview remains available.

## Distribution note

The default GitHub Actions build is ad-hoc signed and not notarized. macOS Gatekeeper may warn or block the downloaded app. A Developer ID signed and notarized build is required for a smoother first launch. The DMG checksum is published alongside the download.
